🪶 飞书机器人（双向对话）

把人格接进你的飞书：在飞书里私聊或 @机器人，它就会回复。走长连接，本机即可，无需公网地址。

怎么拿 App ID / Secret？（点开看 4 步）
  1. 去 飞书开放平台 open.feishu.cn → 创建「企业自建应用」
  2. 在「凭证与基础信息」复制 App ID 和 App Secret
  3. 「添加应用能力」→ 开启机器人；「权限管理」加上 im:message 收发消息权限
  4. 「事件订阅」→ 订阅方式选 长连接 → 添加事件 接收消息 im.message.receive_v1 → 发布版本

🖱️ 桌面操作（让人格动你的鼠标键盘）

授权后，人格能截屏看画面、点鼠标、敲键盘，帮你处理没有 API、只能在界面里点的活。这是高权限能力，默认完全关闭。

安全说明（务必点开看）
  • 所有动作只在你本机执行，不联网外传；每个动作都会写入本地审计日志。
  • 急停：把鼠标猛甩到屏幕左上角即可立即中止人格的一切自动操作。
  • 人格被告知：绝不替你点「删除 / 购买 / 发送 / 转账」这类不可逆按钮。
  • 建议日常用「逐步确认」模式，每个控制动作执行前都问你一句。

💬 企业微信 / 微信公众号

把人格接进企业微信或公众号：用户发消息，人格回复。两者都走回调模式，需要一条内网穿透隧道把本机暴露成公网地址。

怎么配（含内网穿透方案）？点开看
  1. 开隧道：装 cpolar / ngrok / frp 任一，把本机 9100 端口映射出去，得到一个公网 https 地址（如 https://xxx.cpolar.cn）。
  2. 回调 URL = 你的公网地址 + /integrations/wechat/callback，填进微信后台「接收消息服务器配置」。
  3. 在微信后台自定义 Token 和 EncodingAESKey（43 位，可随机生成），消息加解密方式选安全模式，一并填到下面。
  4. 企业微信：再填 CorpID / 应用 Secret / AgentId（用于主动推送回复）。公众号：填 AppID / AppSecret（客服消息需认证服务号）。
  5. 保存并勾选启用 → 回微信后台点「保存」，它会来验证回调 URL，通过即接通。

注：微信回调有 5 秒限制，人格回复较慢，所以先即时确认、答案稍后由「主动推送」发回——属正常现象。
