## 🏰 护城河聚焦（2026-06 更新，最高优先）

> 依「2026 过时排查」结论：停止特性军备竞赛，转夯实护城河。原路线图按"加功能 / 抢用户"
> 编排，但 2026 年真正稀缺的不是功能，而是**别人难复制的结构性优势**。

**Anima 的护城河 = 三位一体，缺一不可：**

1. **厚 Harness（技术护城河）** — 输出质量天花板由 harness 决定、而非"租到哪个模型"。
   v1.3 已落地 Verify 闸门 / 失败记忆 / 代码索引 / Agentless 管道；v1.3.1 再加
   **解法记忆（hindsight note）+ Harness 自演化提案**，让 harness 随真实失败数据进化。
   研究背书：AHE 论文（arXiv:2604.25850）——增益来自工具/中间件/记忆的演化，而非换模型、调 prompt。
2. **本地优先（信任护城河）** — 数据在用户机器上，记忆不上云。隐私 = 情感陪伴产品的命根，
   也是大厂因商业模式难复制的点。这条永不让步。
3. **角色化陪伴（叙事护城河）** — 一个有记忆、有人格、能边教边做的「她」，而非又一个聊天框。
   这是产品叙事，也是用户留存的根。

**重排优先级**：harness 深度 & 自演化　>　新功能。每个 harness 改动用 eval 自主完成率验真伪
（见 `eval/ablation_demo.py` 的判别力自检），完成率没动 = 没起作用，回去查，而不是继续堆功能。

**实际进度（截至 2026-06）**：记忆系统（M1–M10）/ 人格合并（「她」）/ v1.2.x 工具对标 /
v1.3 厚 harness 全部落地，910+ 测试绿；CI 已发版 v1.3.0（本补丁 v1.3.1 修发版漏修）。
工程基线（原 Phase 0）实质完成，重心转入 **Phase 1 公测 + 护城河夯实**。

## Phase 3 — Agent 社交网络（融资标的）

**概念**：你的 Anima 认识我的 Anima，她们交换信息，分别向各自的主人报告。

**这是什么**：
- Agent 之间有身份（Anima Identity，类似 DID）
- Agent 可以"结识"，前提是主人授权
- 结识后，定期交换各主人允许共享的信息
- 返回给主人的形式：Anima 的一次对话汇报

**MVP（Agent 名片）**：
- 每个 Anima 实例生成一张身份卡（json + 二维码）
- 可以发给朋友，对方导入后，两个 Agent 建立"认识"关系
- 第一步：仅交换公开信息（用户主动设置的自我介绍）

**融资 pitch 核心叙事**：
> "我们不是在做 AI 助手，我们在建立第一个 Agent 社会网络。
> 每个人拥有一个有记忆、有人格、有社交关系的 AI 分身。
> 当这个网络达到规模，人类的信息流通将发生根本性变革。"
