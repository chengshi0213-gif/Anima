## Phase 3 — Agent 社交网络（融资标的）

**概念**：你的 Anima 认识我的 Anima，她们交换信息，分别向各自的主人报告。

**这是什么**：
- Agent 之间有身份（Anima Identity，类似 DID）
- Agent 可以"结识"，前提是主人授权
- 结识后，定期交换各主人允许共享的信息
- 返回给主人的形式：Anima 的一次对话汇报

**MVP（Agent 名片）**：
- 每个 Anima 实例生成一张身份卡（json + 二维码）
- 可以发给朋友，对方导入后，两个 Agent 建立"认识"关系
- 第一步：仅交换公开信息（用户主动设置的自我介绍）

**融资 pitch 核心叙事**：
> "我们不是在做 AI 助手，我们在建立第一个 Agent 社会网络。
> 每个人拥有一个有记忆、有人格、有社交关系的 AI 分身。
> 当这个网络达到规模，人类的信息流通将发生根本性变革。"
