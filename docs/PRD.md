# Anima — 产品需求文档（PRD）
**版本**: v0.1 · **日期**: 2026-05-25 · **作者**: Anima Team

---

## 一、产品使命

> **Anima 是一个宣言，也是一个工具。**
>
> 在 AI 成为基础设施的时代，我们不问"AI 能做什么"，而是问"人与 AI 共同构建的世界是什么样的"。
> Anima 是对这个问题的第一个答案：一个本地运行的、有记忆的、有人格的 AI 团队，陪你站在新旧世界的边界上。

**一句话定义**：Anima 是你的私人 AI 团队，本地运行，真正记得你，每个成员有独立人格与专长。

**IP 归属**：Anima 是"重建地平线"宇宙的第一个产品。晞（xī）是这个宇宙的第一道光。

---

## 二、用户画像

### Phase 0 内测用户（当前阶段）
- **核心用户**：创作者、独立开发者、研究生、OPC 老板
- **痛点**：用过 ChatGPT/Claude，但每次都要从头解释自己；不信任云端数据；想要真正"懂我"的 AI
- **使用场景**：每天工作开始时的问题拆解、创作思路整理、技术任务辅助、情绪陪伴

### Phase 1 公测用户
- 扩展到：内容创作者、知识工作者、独立研究者
- 获客渠道：Build in Public（小红书、X/Twitter）、开源社区

### Phase 2 商业用户
- 付费点：云同步记忆、团队版、更多模型接入
- **不做**：企业级、B2B、大规模部署（保持轻量定位）

## 三、核心体验目标

**v1.0 内测的唯一核心体验**：

> 「这是我的私人 AI 团队，他们认识我。」

用户打开 Anima，不是打开一个对话框，而是打开一个**正在等着你的团队**。
Anima 记得你上周说的话，晞知道你现在情绪不好，陶朱帮你把昨晚的想法变成代码。

## 四、功能优先级

### ✅ v1.0 必须有（内测）

| 功能 | 描述 | 优先级 |
|---|---|---|
| **Anima 主对话** | Anima 作为主要入口，有完整人格，记忆注入每次对话 | P0 |
| **记忆系统** | SQLite 本地存储，自动学习用户信息，每次对话注入 | P0 |
| **多 Agent 切换** | Anima/晞/陶朱/守藏四个标签，各有专长 | P0 |
| **Onboarding** | 2 分钟完成配置，立刻感受到差异 | P0 |
| **本地运行** | 无需联网（除 API 调用），数据留本地 | P0 |
| **模型自由选择** | DeepSeek/Claude/Qwen/Kimi/GPT 全支持 | P1 |
| **晨间简报** | 每日开始时，Anima 主动报告今日计划/昨日总结 | P1 |
| **记忆浏览** | 用户可以查看、删除 Anima 记住的内容 | P1 |

### 🔜 v1.5 规划（公测前）

| 功能 | 描述 |
|---|---|
| **工作流** | 用自然语言描述，Anima 帮你设计自动化流程 |
| **知识库** | 上传文档，变成可检索的知识 |
| **Skill 系统** | 守藏定期分析对话，升级各 Agent 的专项能力 |
| **日报/周报** | 守藏生成结构化成长记录 |

### 🔮 v2.0 愿景（融资后）

| 功能 | 描述 |
|---|---|
| **Agent 社交网络** | 你的晞可以认识别人的 Agent，返回给你信息 |
| **Agent 名片** | 每个 Anima 实例有唯一身份标识，可交换 |
| **多端同步** | 本地记忆加密同步到云端 |
| **社区** | Anima 用户可以分享 Skill、工作流模板 |

## 五、功能不做列表（v1.0 明确不做）

- ❌ Web 版 / 移动端（先稳 Windows 桌面）
- ❌ 团队协作 / 多用户
- ❌ 自定义 Agent 创建（用户自己搭 Agent）
- ❌ 插件系统
- ❌ 语音输入（TTS 播放可保留）
- ❌ 任何需要注册账号的功能

---

## 六、成功指标

### Phase 0（内测 10 人）
- 每日活跃率 > 70%
- 每人平均发消息 > 10 条/天
- NPS（净推荐值）> 50
- 至少 3 人主动推荐给别人

### Phase 1（公测 500 人）
- 7 日留存 > 40%
- 月活 > 200
- 有人愿意付费（哪怕 1 元）

## 七、已知风险

| 风险 | 等级 | 应对 |
|---|---|---|
| 一个人维护代码，精力有限 | 高 | 严格控制功能范围，技术债务定期清理 |
| API 成本由用户自己承担 | 中 | 清晰告知，提供成本估算，支持经济模型 |
| 与 ChatGPT/Claude 对比被问 | 中 | 差异化：本地 + 记忆 + 人格 + 团队，不是替代而是搭档 |
| 晞人格设计失败（没有灵魂感） | 高 | 详见 XI_IDENTITY.md，这是最高优先级 |
| 毕业压力导致开发中断 | 高 | Phase 0 在毕业前完成，发布节奏与学业不冲突 |
