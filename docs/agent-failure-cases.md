# Agent 失败案例库

> 每条记录：任务 → Agent 做错了什么 → 应该怎么做 → 对应提示词修订
> 来源：用户打断（H1 cancel/steer）、用户负面反馈、熔断触发（H6）的会话
> 节奏：每个 minor 版本发版前过一遍，把新规则合入提示词

---

## 格式模板

```
### [编号] 简要描述
- **日期**：YYYY-MM-DD
- **触发方式**：cancel / steer / 熔断 / 用户反馈
- **任务**：用户要求做什么
- **错误行为**：Agent 实际做了什么
- **正确行为**：应该怎么做
- **提示词修订**：加了什么规则 / 改了哪段提示词
```
