## 一、合盘四层判断框架

**核心原则：** 两人命盘的缘分深浅，由以下四个层次决定，层次越深越准确。

| 层次 | 判断内容 | 重要性 |
|------|---------|--------|
| 第一层 | 对方命宫星曜是否符合我夫妻宫特质 | 基础筛选 |
| 第二层 | 双方夫妻宫的星曜方向是否一致 | 感情诉求匹配 |
| 第三层 | 我的四化有没有飞入对方感情宫位 | 缘分深浅核心 |
| 第四层 | 流年四化同时引动双方感情宫位 | 时机成熟信号 |

---

## 二、第一层：命宫星曜匹配

**判断方法：**
1. 看自己的夫妻宫坐什么主星（代表理想配偶类型）
2. 看对方命宫坐什么主星（代表对方的核心性格）
3. 两者是否在星性上相符或互补

**高匹配组合参考：**
- 夫妻宫紫微 → 对方命宫有紫微系星曜（主见、气场、领导力）
- 夫妻宫天府 → 对方命宫稳重踏实（天府、天相、武曲）
- 夫妻宫太阳 → 对方热情外向（太阳、贪狼、天同）
- 夫妻宫太阴 → 对方细腻感性（太阴、天机、天梁）
- 夫妻宫武曲 → 对方务实执行（武曲、七杀、廉贞）

**注意：** 命宫星曜相符是基础，但不是唯一标准，还需看四化。

## 三、第二层：双方夫妻宫互照

**判断方法：**
- 看我的夫妻宫在哪个地支
- 看对方的夫妻宫在哪个地支
- 两宫是否在三方四正关系上有互动

**方向一致的信号：**
- 双方夫妻宫互为对宫（六冲不一定凶，有时代表强烈吸引）
- 双方夫妻宫在三合位置（寅午戌·申子辰·亥卯未·巳酉丑）
- 双方夫妻宫主星象意互补（一方贪狼·另一方天相）

**方向不一致的信号：**
- 双方对感情的期待完全不同（一方要自由，一方要稳定）
- 夫妻宫的主星五行相克

## 四、第三层：四化飞入对方命盘（核心层）

这是判断缘分深浅最重要的层次。

### 我的生年四化飞入对方哪里

**最强缘分信号：**
- 我的禄星飞入对方命宫 → 对方感受到我的善意和吸引力，天然想靠近
- 我的禄星飞入对方夫妻宫 → 我对对方有感情的能量投入 ★最佳缘分信号
- 我的科星飞入对方命宫 → 对方觉得我有气质有才华，欣赏我
- 对方的禄星飞入我的夫妻宫 → 对方对我有感情能量 ★双禄交流最佳

**需关注的信号：**
- 我的忌星飞入对方夫妻宫 → 我对对方在感情上有阻滞，双方可能在感情关系上有摩擦
- 我的忌星飞入对方命宫 → 对对方有消耗性影响，长期相处有损耗
- 对方的忌星飞入我的命宫 → 对方对我有阻滞能量，相处有压力感

**实操：**
用对方的生年天干，查四化表，得出对方的禄权科忌各落在哪颗星，再看这颗星在**我的**命盘里落在哪个宫位。

## 五、第四层：流年四化同时引动

**判断方法：**
1. 看我的命盘在该流年：夫妻宫有没有化禄科权入
2. 看对方的命盘在该流年：夫妻宫有没有化禄科权入
3. **双方同时有吉化入夫妻宫** → 这一年两人的感情宫位同时"开门"，缘分真正成熟

**最强时机信号：**
- 双方流年夫妻宫同时得化禄 → 双方对感情都开放，时机最好
- 一方流年命宫·另一方流年夫妻宫同时有禄 → 主动方遇到开放的缘分

**时机不合的信号：**
- 我这边感情宫位开着，对方感情宫位有化忌 → 对方今年不在感情状态，强求无用
- 双方流年夫妻宫同时有化忌 → 这一年不是两人感情落地的时机

## 六、强缘分信号 vs 需谨慎信号

### 强缘分信号（同时满足越多越好）
1. 对方命宫星曜符合我夫妻宫的星象特质
2. 双方夫妻宫在三方四正有互动关系
3. 我的禄星飞入对方命宫或夫妻宫
4. 对方的禄星飞入我的夫妻宫或命宫
5. 双方今年流年感情宫位同时有吉化

### 需谨慎信号
1. 我的忌星飞入对方夫妻宫或命宫
2. 对方的忌星飞入我的命宫或夫妻宫
3. 双方夫妻宫同时有化忌
4. 对方命宫星曜与我的夫妻宫星象完全相反
5. 双方流年感情宫位时机不同步

### 综合判断规则
- 强信号3个以上 → 缘分深，时机对，可积极发展
- 强信号1-2个，谨慎信号较少 → 有缘分，但需时间磨合
- 谨慎信号2个以上 → 有吸引力但阻力也大，需理性评估
- 谨慎信号3个以上 → 这段关系消耗性较大，需慎重

---

## 七、合盘实操步骤

**已知对方生年，快速判断步骤：**

1. 查对方生年天干对应的生年四化（查四化表）
2. 对方的化禄落在哪颗星 → 这颗星在**我的**命盘哪个宫位
3. 对方的化忌落在哪颗星 → 这颗星在**我的**命盘哪个宫位
4. 我的化禄落在哪颗星 → 这颗星在**对方的**命盘哪个宫位（需对方出生信息）
5. 综合判断双方四化互飞的情况

**最简单的判断：**
- 对方禄星落我夫妻宫/命宫 → 有缘
- 对方忌星落我命宫/夫妻宫 → 有阻力
- 双方互有禄星落对方感情宫位 → 强缘分，珍贵的双向吸引
