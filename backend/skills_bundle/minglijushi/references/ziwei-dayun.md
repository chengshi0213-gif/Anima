## 一、大限分析框架

**大限 = 这十年的整体气候**

分析步骤：
1. 确定大限命宫所在（从本命命宫起，按顺/逆方向推算当前大限宫位）
2. 看大限命宫的主星，这十年以该星象意为主导
3. 看大限命宫的三方四正（大限的财官迁形成新的格局）
4. 看大限宫干飞出的四化，这十年的主要动力方向
5. 大限命宫叠本命哪个宫位 → 该宫位的事项是这十年重心

**大限质量判断：**
- 大限命宫有吉星+化禄权科 → 顺运，该十年整体上升
- 大限命宫有煞星+化忌 → 逆运，该十年多阻碍
- 大限命宫叠本命重要宫位（如官禄、财帛）→ 该领域是这十年主轴

## 二、流年三盘叠加

**三层叠加公式：**
本命盘（先天底色）→ 大限盘（十年气候）→ 流年盘（当年触发）

**叠加逻辑：**
- 流年命宫 = 当年太岁所在地支宫位
- 流年命宫叠大限命宫 → 这一年是大限的爆发年
- 流年命宫叠本命命宫 → 本命能量被流年直接激活
- 流年命宫叠本命身宫 → 全年状态最佳，内外共振

**流年权重：**
- 大运顺 + 流年顺 → 最好，重大机会年
- 大运顺 + 流年逆 → 小有波折，基调仍好
- 大运逆 + 流年顺 → 改善有限，基调仍难
- 大运逆 + 流年逆 → 最凶，务必低调

## 三、流年四化落宫判断

当年天干飞出四化，看落在本命盘/大限盘的哪个宫位：

**禄入各宫：**
- 禄入流年命宫 → 当年整体运势佳，财缘人缘俱好
- 禄入流年财帛 → 当年收入直接增加 ★财运最强信号
- 禄入流年官禄 → 事业顺遂，有名有利
- 禄入流年夫妻 → 感情顺遂，有姻缘

**权入各宫：**
- 权入流年命宫 → 当年气场最强，决断力强 ★
- 权入流年官禄 → 当年事业有权位，主导力强
- 权入流年财帛 → 主动求财，财务决策年

**科入各宫：**
- 科入流年官禄 → 当年事业有名誉，专业被认可 ★
- 科入流年命宫 → 当年名声好，贵人多
- 科入流年夫妻 → 感情有名分

**忌入各宫：**
- 忌入流年命宫 → 当年多是非，个人运势受阻
- 忌入流年财帛 → 当年财务有损失，漏财年
- 忌入流年夫妻 → 当年感情有波折 ★婚姻警示
- 忌入流年官禄 → 当年事业有阻，但会很努力
- 忌入流年父母 → 合同文书需谨慎，长辈关系有阻 ★合同警示
- 忌入流年疾厄 → 健康需关注

## 四、四季运势节奏

判断当年哪个季节最强，以流年命宫五行为准：

| 流年命宫五行 | 最强季节 | 最弱季节 |
|------------|---------|---------|
| 木（寅卯辰）| 春季（农历1-3月）| 秋季（金克木）|
| 火（巳午未）| 夏季（农历4-6月）| 冬季（水克火）|
| 土（辰戌丑未）| 四季末月 | 木旺之春（木克土）|
| 金（申酉戌）| 秋季（农历7-9月）| 夏季（火克金）|
| 水（亥子丑）| 冬季（农历10-12月）| 土旺季节（土克水）|

**实用规则：** 在当年最强的季节集中冲刺重要事项，在最弱的季节守稳保成。

## 五、各大限宫位人生主题

| 大限命宫 | 该十年主题 |
|---------|----------|
| 命宫 | 自我整合·人生方向确立期 |
| 兄弟宫 | 手足·朋友·合作关系是主轴 |
| 夫妻宫 | 感情婚姻是主轴·亲密关系重心 ★ |
| 子女宫 | 子女·创作·下属是主轴 |
| 财帛宫 | 赚钱·财务积累是主轴 |
| 疾厄宫 | 健康·劫难·需保重身体 |
| 迁移宫 | 外出·在外发展·环境变动大 |
| 交友宫 | 人际·贵人·竞争者是主轴 |
| 官禄宫 | 事业功名是主轴·拼搏期 ★ |
| 田宅宫 | 家庭·置产·稳固根基 |
| 福德宫 | 精神层面·享受·内在成长 |
| 父母宫 | 长辈关系·文书契约·学习 |

**重要规则：**
大限命宫叠本命哪个宫位，就以该宫位的星曜来看这十年。如大限命宫落本命夫妻宫，则以本命夫妻宫的星曜（而非大限宫位本身的星曜）判断这十年的感情运。
