# 增运调候建议知识库

## 一、增运的本质

增运不是改变命运，而是**顺应用神五行方向，让生活环境与喜用神同频**，减少阻力，放大机会。

核心原则：
- 喜用神：顺势放大，多接触对应方位·颜色·行业·人群
- 忌神：有意识减少接触，尤其在大运逆时更需远离

## 七、大运逆境期的增运策略

当处于逆运（大运忌神）阶段：

1. **降低风险敞口**：不做大投资·不轻易创业·不轻易换工作
2. **蓄力积累**：逆运是充电而非放电的阶段，专注学习和积累
3. **保护用神**：远离克制用神的人和环境
4. **强化喜用神方位颜色**：通过环境调整弥补运势不足
5. **维护健康**：逆运期身体免疫力较低，注意休息

## 八、紫微斗数的增运建议（四化视角）

**顺运年（流年有禄权科入命官财）：**
- 主动出击，扩大行动半径
- 集中在这年最强的季节发力
- 这是"放电"阶段，不要守，要冲

**逆运年（流年有忌星入命官财）：**
- 守住已有成果，不贸然扩张
- 强化喜用神的生活方式
- 在单个好月份局部冲刺，其余时间蓄力

**化忌年的具体应对：**
- 忌入命宫→低调·减少是非·不争不抢
- 忌入财帛→控制支出·不做大额投资
- 忌入官禄→认真做好本职·不争权位
- 忌入夫妻→感情多沟通·避免误解
- 忌入父母→合同仔细看·避免法律纠纷

## 九、命理调候与风水/姓名的关系

**风水：** 居住环境的五行能量可以辅助命局用神
- 喜木火→家中多绿植·灯光明亮·南向或东向房间为主卧
- 喜金水→家居色调冷静·金属装饰·北向较适

**姓名：** 名字笔画五行可作为补充，但效果有限，不可过分依赖

**最终提醒：** 增运建议是辅助工具，真正改变命运轨迹的是自己的选择和行动。命盘只是方向盘，人才是司机。
