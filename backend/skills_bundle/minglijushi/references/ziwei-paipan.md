## 一、命宫与身宫定位

### 命宫
从寅宫起正月，顺时针数至生月止；
再从该宫起子时，逆时针数至生时止，所落之宫即为命宫。

### 身宫
从寅宫起正月，顺时针数至生月止；
再从该宫起子时，顺时针数至生时止，所落之宫即为身宫。

### 十二宫排列（从命宫起，逆时针）
命宫 → 兄弟 → 夫妻 → 子女 → 财帛 → 疾厄 → 迁移 → 交友（奴仆）→ 官禄 → 田宅 → 福德 → 父母

## 三、紫微星位推算

设农历出生日数为A，五行局数为B：

1. 找最小X，使(A+X)能被B整除，C=(A+X)÷B
2. X为偶数：D=C+X；X为奇数：D=C-X（若D为负数则加12）
3. D对应宫位：寅1·卯2·辰3·巳4·午5·未6·申7·酉8·戌9·亥10·子11·丑12

## 四、十四主星安布

### 紫微星系（北斗，从紫微逆时针）
紫微 → 逆一宫：天机 → 跳一宫 → 太阳 → 逆一宫：武曲 → 逆一宫：天同 → 跳两宫：廉贞

### 天府星系（南斗，从天府顺时针）
天府 → 顺一宫：太阴 → 贪狼 → 巨门 → 天相 → 天梁 → 七杀 → 跳三宫：破军

**天府位置：** 从紫微所在宫逆数，紫微在午则天府在寅（具体查安星诀表）

## 七、大限起运

**起运年龄 = 五行局数（粗算）**
精确算法：以节气距离算天数，3天=1年，加上五行局数基数。

**大限顺序：**
- 男命阳年生、女命阴年生：大限从命宫起顺时针走
- 男命阴年生、女命阳年生：大限从命宫起逆时针走

每步大限走10年，命宫→兄弟→夫妻→子女（顺行），依次类推。

## 八、十二宫位含义速查

| 宫位 | 主管事项 | 特殊说明 |
|------|---------|---------|
| 命宫 | 性格·人生主轴·先天禀赋 | 最核心，是命盘枢纽 |
| 身宫 | 后天行为取向·成熟后主导 | 可落在任意六个宫位 |
| 兄弟宫 | 兄弟姐妹·朋友·手足缘 | 也看合伙关系 |
| 夫妻宫 | 婚姻·感情状态·配偶 | 男命妻宫·女命夫宫 |
| 子女宫 | 子女缘·晚辈·创作成果 | 也看下属关系 |
| 财帛宫 | 流动收入·赚钱方式 | 看财来源而非积累 |
| 疾厄宫 | 健康·体质·疾病 | 也看劫难 |
| 迁移宫 | 出行·外在表现·异乡发展 | 命宫的对宫，互为参照 |
| 交友宫 | 朋友·贵人·竞争者 | 也叫奴仆宫 |
| 官禄宫 | 事业·功名·职位·志向 | 命财官迁最重要的宫位之一 |
| 田宅宫 | 不动产·家庭环境·积累 | 看财富积累而非收入 |
| 福德宫 | 精神世界·福报·享受 | 身宫常落此，主精神取向 |
| 父母宫 | 父母·长辈·文件契约 | 也叫相貌宫，看外貌 |
