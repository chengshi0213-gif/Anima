## 一、四化象意精解

**论断口诀：宫位定人事·星情断吉凶·四化寻契机·行运看变化**

### 化禄
- 象意：财禄·享受·人缘·善缘·贵人·解厄·情缘·才艺·忙碌有收获
- 五行：金·西方·秋天
- 本质：该星曜的正面特质被放大·多有所得
- 注意：化禄入疾厄宫≠吉（多情缘于病）

### 化权
- 象意：权势·主导·固执·争执·成就·掌权·力争上游·才干·权威·原则
- 五行：火·南方·夏天
- 本质：该星曜能量被强化，主导性增强
- 注意：化权过强易引发争执，需有制化

### 化科
- 象意：功名·名声·善缘·贵人·名誉·平顺·气质好·学识才艺
- 五行：木·东方·春天
- 本质：该星曜获得名誉加持，贵人相助
- 注意：化科力量较禄权弱，主名誉而非实质利益

### 化忌
- 象意：阻滞·是非·困扰·波折·损失·嫉妒·纠缠·亏欠·破坏
- 五行：水·北方·冬天
- 本质：该星曜负面特质放大，事项受阻
- 注意：化忌不等于绝对凶，要看入何宫、星性、周边星曜

## 二、四化入各宫含义

### 化禄入各宫
- 入命宫：个人魅力强·人缘好·财运佳
- 入兄弟宫：兄弟友好·朋友助力
- 入夫妻宫：感情顺遂·配偶助力
- 入子女宫：子女缘深·部属得力
- 入财帛宫：财禄丰厚·收入增加·★最直接的财运信号
- 入疾厄宫：需注意（多情缘于疾）
- 入迁移宫：外出顺利·在外有贵人
- 入交友宫：朋友助力·贵人多
- 入官禄宫：事业顺遂·有名有利
- 入田宅宫：家庭和乐·不动产有益
- 入福德宫：精神享受·生活质量好
- 入父母宫：长辈缘深·文书顺利

### 化权入各宫
- 入命宫：自我意识强·有主导力·★个人气场最强信号
- 入官禄宫：事业强势·有权位·掌控力强
- 入财帛宫：主动求财·财务决策力强
- 入夫妻宫：感情中主导性强（易有控制欲）
- 入田宅宫：掌管家中事务·不动产有主导权
- 入福德宫：精神层面强势，追求高标准

### 化科入各宫
- 入命宫：名声好·气质佳·有贵人
- 入官禄宫：事业有名誉·专业受认可·★最佳名誉信号
- 入财帛宫：财务有条理·靠专业技能赚钱
- 入夫妻宫：感情有名分·配偶名声好
- 入父母宫：与长辈文书关系顺利

### 化忌入各宫
- 入命宫：个人运势受阻·多是非·需低调
- 入兄弟宫：兄弟手足有是非·朋友带来麻烦
- 入夫妻宫：感情有波折·配偶有困扰·★婚姻最大警示
- 入子女宫：子女缘薄·或子女有麻烦
- 入财帛宫：财来财去·财务损失·漏财
- 入疾厄宫：健康需注意·该宫对应脏腑需留意
- 入迁移宫：外出不顺·在外多是非
- 入交友宫：朋友带来麻烦·小人出没
- 入官禄宫：事业有阻滞·但主对工作认真负责（双面性）
- 入田宅宫：家庭有纠纷·不动产有麻烦
- 入福德宫：精神压力大·内心纠结
- 入父母宫：与长辈关系有阻·文件合同需仔细·★合同法律警示

## 三、三方四正分析法

**核心规则：不可单宫论断，必须看三方四正整体。**

三方四正 = 本宫 + 对宫 + 本宫三合的两个宫位（共四个宫位）

最重要的四正线：
- **命·财·官·迁**（命宫·财帛宫·官禄宫·迁移宫）→ 人生格局主轴
- **命·夫·子·奴**（命宫·夫妻宫·子女宫·交友宫）→ 人际关系轴
- **父·疾·福·田**（父母宫·疾厄宫·福德宫·田宅宫）→ 生活质量轴

**分析步骤：**
1. 看本宫主星及四化
2. 看对宫星曜（借入本宫参考）
3. 看三合宫的星曜会照
4. 综合四个宫位给出判断，不以任何单一宫位为准

## 四、格局判断

### 三合派格局（星曜组合形成）
**贵格：**
- 府相朝垣：紫微在子午，天府天相三方照命 → 极贵
- 日月并明：太阳太阴同宫或三方，且庙旺 → 格局高
- 君臣庆会：紫微会左辅右弼·文昌文曲 → 才华与权威
- 雄宿朝垣：七杀在子午守命，百官朝拱 → 武贵之格
- 禄合鸳鸯：禄存与化禄同宫 → 双禄主大富

**败格：**
- 火铃夹命：火星铃星夹住命宫 → 凶
- 空劫夹命：地空地劫夹命宫 → 极耗散
- 廉贞七杀：廉贞七杀同宫 → 孤克之格
- 十恶大败：太阴化忌逢火铃 → 财败

### 四化派格局判断
- 三吉化（禄权科）入命宫三方 → 格局高
- 化忌落陷且三方逢煞 → 格局低
- 化忌入命宫·迁移宫 → 凶力最大

## 五、宫位互动规律

### 命迁线（命宫←→迁移宫）
- 命宫看内在、先天性格
- 迁移宫看外在表现、在外际遇
- 两宫互照，判断内外是否一致

### 官财线（官禄宫←→财帛宫）
- 官禄宫看事业方向和成就
- 财帛宫看收入和财运
- 两宫的星曜和四化叠加判断财富积累方式

### 夫福线（夫妻宫←→福德宫）
- 夫妻宫看感情状态和配偶
- 福德宫看精神需求和感情标准
- 两宫联合分析，判断感情的深层诉求

### 田疾线（田宅宫←→疾厄宫）
- 田宅宫看家庭环境和资产积累
- 疾厄宫看健康和劫难
- 两宫的忌星分布判断健康隐患
