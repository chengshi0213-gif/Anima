## 一、大运分析框架

大运是命局在时间轴上的气候变化，命局是先天底色，大运决定十年整体气场。

**分析步骤：**
1. 判断大运五行与命局用忌神的关系
2. 判断大运干支与命局的合冲刑害
3. 判断大运对格局的影响（成格/破格）
4. 天干管前5年，地支管后5年（分段参考）

**大运质量分级：**
- 上运：大运用神与命局同气，格局得扶 → 事事顺遂
- 平运：大运对命局影响中性，格局不破不成
- 逆运：大运忌神入命，格局受冲破 → 困难重重

## 二、大运与命局互动规律

### 大运冲命局宫位
- 冲年支 → 祖业动荡、家庭变化
- 冲月支 → 工作变动、父母健康
- 冲日支（夫妻宫）→ 婚姻感情波折
- 冲时支 → 子女、晚年事项有变

### 大运合命局
- 合用神所在 → 该宫位事项受益
- 比劫合财星 → 劫财夺财，财运受损
- 官星合日支 → 感情婚姻进展（女命）

### 大运入格/破格
- 大运为格局用神 → 格局加强，人生上升
- 大运为格局忌神 → 格局受冲，诸事不顺
- 相神受损 → 格局失去支撑，成就打折

## 三、流年分析框架

**三层叠加公式：**
命局（底色）+ 大运（气候）+ 流年（具体触发）= 当年运势

**流年权重组合：**
- 大运顺 + 流年顺 → 极好，重大机会
- 大运顺 + 流年逆 → 小有波折，整体仍可
- 大运逆 + 流年顺 → 略有改善，基调仍难
- 大运逆 + 流年逆 → 最凶，需特别谨慎

### 流年太岁六大互动
1. 太岁冲命局：该宫位代表人事有大变动
2. 太岁合命局用神：该年用神得助，喜事临门
3. 太岁合命局忌神：忌神被合住，反而平顺
4. 太岁冲命局忌神：忌神被冲走，也可转好
5. 太岁刑命局：多是非·官非·健康问题
6. 太岁与命局三合/半合：该五行势力大增

## 四、人生关键节点判断

### 事业起跳年
用神流年 + 大运顺 + 食伤/官/财星入命
→ 特别是食神生财格遇财星流年、官印格遇官星流年

### 财运爆发年
偏财或正财透干 + 大运行财运 + 无劫夺冲克
→ 财星流年冲命局财库（辰戌丑未）：财库开，有大收入

### 婚姻感情年
- 男命：财星（妻星）流年透干 + 日支无冲
- 女命：官星（夫星）流年透干 + 日支无冲
- 大运亦顺婚姻宫 → 婚期

### 凶险年份信号
- 流年冲日柱 → 本人健康·婚姻受冲击
- 流年忌神入命 + 大运也行忌神 → 双重叠加最凶
- 岁运并临：流年与大运地支相同 → 力量倍增

## 六、各大运阶段人生规律

### 青年期（0-20岁）
- 印绶大运 → 学业顺，有长辈提携
- 食伤大运 → 活泼多才，学业需专注度
- 官杀大运 → 规矩多，家有变故可能

### 中年期（20-50岁，事业财运婚姻主战场）
- 财官大运 → 事业财运上升，婚姻进展
- 比劫大运 → 竞争激烈，财来财去，感情第三方
- 食伤大运 → 才华发挥，创业创作好时机

### 晚年期（50岁后）
- 印绶大运 → 安稳，有子女供养
- 官杀大运且无制 → 多病痛是非
- 比劫大运 → 财务不稳，需提前规划
